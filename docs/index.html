edgegoat: edge case test inputs for JavaScript

The inputs that break code, ready to drop into your tests.

284 curated, documented edge cases for time zones, daylight saving time, dates before 1970, unicode test strings, -0 and NaN, URLs, paths and JSON. Each one says why it breaks code. Works with Vitest, Jest, node:test and Mocha, in TypeScript or JavaScript, with zero dependencies.

Quick start View on GitHub

Quick start

npm install --save-dev edgegoat
import { test, expect } from 'vitest';
import { dates, withTimeZone } from 'edgegoat';

test.each(dates({ tags: ['dst'] }))('$label', ({ value, zone }) => {
  withTimeZone(zone, () => expect(addDays(value, 1).getHours()).toBe(value.getHours()));
});

Every generator returns an array of { label, value, why, tags } objects, so it plugs straight into test.each. Filter with { tags: [...] } or { exclude: [...] }, pick zones with dates({ zone: 'Europe/Berlin' }).

What is in the box

  • Dates 46 cases

    DST gaps and overlaps, New Year in 7 zones, leap days, before 1970, 2038, year 10000

  • Time zones 18 cases

    Curated IANA zones: +05:45, +14:00, -11:00, 30 minute DST, midnight DST

  • Strings 49 cases

    Emoji, surrogate pairs, NFC vs NFD, bidi, invisible spaces, Turkish i, newlines

  • Numbers 51 cases

    -0, NaN, Infinity, safe integer limits, 0.1 + 0.2, 1e21, numeric strings and BigInt

  • URLs and emails 54 cases

    WHATWG parser surprises, SSRF and open redirect shapes, RFC 5321 limits

  • Paths 30 cases

    Windows vs POSIX, UNC, reserved names, traversal, NFD file names

  • JSON 22 cases

    10000 levels deep, duplicate keys, 2^53 + 1, __proto__, BOM

  • Arrays 14 cases

    Holes, length 2^32 - 1, NaN membership, default sort, too big to spread

  • Helpers 4 functions

    withTimeZone, withFrozenTime, check, assertNoThrow

Bugs these inputs found

Real bugs of this kind, fixed upstream by the author of edgegoat in widely used projects. The library packages the inputs that exposed them.

  • github/relative-time-element#384: The "is this the current year?" check used UTC instead of the display time zone, so dates near New Year showed or hid the year incorrectly.
  • mozilla/pdf.js#22017: util.printf dropped the sign of negative numbers greater than -1, such as -0.5.
  • google/budoux#1411: Text segmentation could split a surrogate pair, producing half an emoji.
  • microsoft/vscode-js-debug#2423: trimEnd style truncation could cut a surrogate pair in half.
  • salesforce/tough-cookie#644: A cookie with an infinite max-age has to be treated as never expiring.
  • vuejs/core#15618: A fix in the Vue 3 compat build.
